### ImageTextSelector

![Output Structure](OutputView.svg)

#### Purpose

`ImageTextSelector` is the shared, format-agnostic policy that decides what text describes an image.
A backend gathers whatever a document offers about a picture — an authored alt-text description, a
drawing title, an adjacent caption, an embedded object name, the nearest heading, the media part name
— and hands the set here; the selector ranks the candidates, discards empty and auto-generated names,
and reports how confidently the chosen text describes the picture. Its single responsibility is the
ranking-and-honesty decision, so every current and future backend (Word today; PowerPoint, Excel, and
Visio later) names images and writes alt text the same way, and the decision that a heading may name a
file but must never be asserted as a description lives in exactly one place.

#### Data Model

`ImageTextSelector` is a `static class` — a pure policy with no state, safe for concurrent use. It
operates on three supporting value types, all immutable positional records or enumerations documented
as supporting types (D8) of the Output subsystem:

- **`ImageTextSource`** (`enum`) — the origin of a candidate, in decreasing directness:
  `Description`, `Title`, `Caption`, `PictureName`, `Heading`, `Uri`. The declaration order **is** the
  preference order.
- **`ImageTextConfidence`** (`enum`) — how far the chosen text may be trusted: `Descriptive`
  (authored text or a meaningful object name), `Contextual` (a nearby heading), `Fallback` (the media
  name).
- **`ImageTextCandidate`** (`record`) — one `(string? Text, ImageTextSource Source)` a backend offers;
  null or whitespace text is treated as absent.
- **`SelectedImageText`** (`record`) — the result `(string Text, ImageTextSource Source,
  ImageTextConfidence Confidence)`; `Text` is trimmed and never empty.

#### Key Methods

- **`SelectedImageText? Select(IEnumerable<ImageTextCandidate>)`** — ranks the candidates and returns
  the highest-ranked usable one, or `null` when none carries text. A candidate is skipped when its
  trimmed text is empty, and a `PictureName` candidate is skipped when its text is an auto-generated
  placeholder. The winner's confidence is derived from its source: `Description`/`Title`/`Caption`/
  `PictureName` → `Descriptive`, `Heading` → `Contextual`, `Uri` → `Fallback`. Rejects a null
  argument (`ArgumentNullException`). Pure.
- **`bool IsAutoGeneratedName(string?)`** — reports whether an object name is a tool-assigned
  placeholder: an empty name, or a generic base name (`picture`, `image`, `graphic`, `chart`,
  `object`, `diagram`, `drawing`, `shape`, `group`, `freeform`, `rectangle`, `oval`,
  `content placeholder`, `text box`, `placeholder`) followed by an optional number. A meaningful name
  that merely ends in a number (for example `Blueprint 2`) is **not** matched, because its base is not
  a placeholder. Pure and culture-independent.
- **`string SourceName(ImageTextSource)`** — projects a source to its stable camelCase provenance
  string (`description`, `title`, `caption`, `pictureName`, `heading`, `uri`), which a backend records
  in the manifest so a reader can tell an authored description apart from a heading. Total; throws on an
  unknown source. Pure.

#### Error Handling

`Select` rejects a null candidate sequence (`ArgumentNullException`); individual candidates may carry
null text and are simply ignored. `SourceName` and the internal confidence mapping throw
`ArgumentOutOfRangeException` on an unknown source, so a source added to the enumeration without a
projection fails loudly rather than defaulting silently to the wrong tier. The selector never throws on
document content — an absence of usable text is reported as `null`, never a guessed description.

#### Dependencies

- **`ImageTextSource`, `ImageTextConfidence`, `ImageTextCandidate`, `SelectedImageText`** — supporting
  types (D8) declared alongside the selector.
- `System.Text` (`StringBuilder`) only — no runtime NuGet dependencies; `DocDown.Word` stays fully
  managed by depending on this policy rather than any native code.

#### Callers

`WordOpenXmlReader` gathers a drawing's candidates and calls `Select`; `WordOpenXmlImageReader` appends
the media-name fallback candidate, invokes the selector, and turns the result into an image reference's
naming hint, alt text, and manifest description. The confidence tier is what makes the Word markdown
writer assert alt text only for a `Descriptive` selection while still allowing a `Contextual` heading to
seed the file name. See _WordOpenXmlReader Design_ and _WordMarkdownWriter Design_.
